================ 验证状态 ================
[✓] 博爱书屋 / 天人小说网：
    已实地抓取真实页面，逐一核对搜索、详情、目录、正文的选择器。
    - 博爱书屋：目录分页，已用 select#indexselect 一次取全部分页；
      正文按 _N.html 分页，已写 JS 自动合并，并过滤广告/"更多内容加载中"/章末提示。
    - 天人小说网：帝国CMS，GB2312。搜索是 POST，关键词按 GBK 编码（已在 searchUrl
      的 charset 参数中处理）。以同人/二次创作小说为主。

[⚠] 69书吧（69shuba）：未实地验证。
    本机抓取出口 IP 被该站 Cloudflare「Just a moment...」JS 质询拦截(HTTP 403)，
    无法在抓取环境校验选择器。规则基于 69shuba.com 公开通用结构编写。
    真机 / 住宅宽带 IP 通常可正常过盾访问。
    导入后若搜索或正文为空，多半是某个 class 名变了，按页面实际结构微调
    ruleSearch / ruleContent 即可。

================ 导入方法 ================
阅读 App → 我的 → 书源管理 → 右上角 ··· → 本地导入 → 选择 json 文件
（或选 all_书源合集.json 一次性导入全部 3 条）
